# Система управления контентом для мультиформатного медиа-портала

Учебный проект по дисциплинам «Язык Java» и «Нереляционные базы данных» для защиты в рамках проектного практикума.

## Задача

Разработать REST API для публикации и управления статьями, видео и подкастами. Редакция создаёт и обновляет материалы, читатели получают опубликованный контент и подборку популярных материалов.

## План реализации

- Java и Spring Boot (Spring Web, Spring Data, Spring Security).
- PostgreSQL для пользователей, ролей, материалов и эпизодов подкастов.
- Регистрация и аутентификация. Доступ на запись для авторизованных редакторов.
- Redis Sorted Sets для рейтинга по просмотрам. Демонстрационный запрос возвращает топ-10 статей за последний час.
- Swagger/OpenAPI, Docker Compose и демонстрационный сценарий для проверки.

Статус: репозиторий и описание подготовлены. Реализация и инструкция запуска будут добавлены по мере разработки.
